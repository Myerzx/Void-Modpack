# Pacote dedicado

Diretório reservado para a futura fonte reproduzível do servidor.

Nenhum arquivo do runtime bruto foi promovido nesta fase. A promoção depende de:

- compatibilidade com um cliente publicado;
- resolução de origem e licença dos mods e datapacks;
- remoção de segredos e dados persistentes;
- classificação de lado cliente/servidor;
- boot e conexão em ambiente limpo.
